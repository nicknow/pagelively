# 07 — Toolchain

Locked here; the _why_ and citations live in ADRs 0002–0004. Phase 0 seeded everything
(ADR 0001); Phase 2 verified each choice against current docs and pins the versions in
`package.json`.

## Language & runtime

- **TypeScript** `strict`, target **ES2022**, ES-module **module-worker** format (the test
  tooling requires modules — verified; no `nodejs_compat` — keeps the bundle small, §15).
- **Env** lives in `worker-configuration.d.ts`, generated by `npm run types`
  (`wrangler types`) and committed; regenerate after any `wrangler.toml` change (ADR 0001 —
  including the `[cache] enabled = true` block when S13 adds it).
- Installed: TypeScript 6.0.3, Wrangler 4.116.0 (dev deps, pinned caret).

## Dependencies (runtime — deliberately tiny)

Only **two runtime deps** (ADR 0002):

| Package  | Version (installed)     | Purpose                               | Verified                                                                                                                       |
| -------- | ----------------------- | ------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| `marked` | ^18.0.7                 | Markdown → HTML (§7, §14)             | Context7/official repo: `marked.parse(md[, opts])` sync, isomorphic (browsers/servers/workers), no built-in sanitizer since v5 |
| `jose`   | latest (pin on install) | Access JWT verification (JWKS, RS256) | Cloudflare changelog example uses `createRemoteJWKSet` + `jwtVerify`                                                           |

- **No router library** (ADR 0002): the routing surface is ~10 literal path rules
  (`classifyPath`, 02) — a framework adds bytes for no benefit and less testability.
- **No `nanoid`** (spec §4 allows "or Web Crypto random"): `crypto.getRandomValues` →
  8–10 URL-safe chars; zero bytes, zero supply-chain surface.
- **No sanitizer dependency**: `ALLOW_RAW_HTML_IN_MD=false` is implemented as a custom
  `marked` renderer (`html`/`tag` tokens escape instead of pass through) — the sanctioned
  v5+ mechanism (Context7-verified); `true` (default) passes raw HTML through for the
  single-operator trust model (§7; risk R12 documented).
- Deferred: `fflate` (zip upload, §16), DOMPurify (only if untrusted input ever appears — it
  doesn't in v1).

## Test tooling (ADR 0003)

- **Vitest 4.1.10 + `@cloudflare/vitest-pool-workers` 0.19.1** (latest at verification): the
  Cloudflare-recommended unit-test integration; tests run inside `workerd` via Miniflare with
  real local emulation of R2/D1/KV (verified docs) and per-test-file isolated storage.
- Config: `cloudflareTest()` plugin reading `wrangler.toml`; D1 migrations via
  `readD1Migrations` + `applyD1Migrations` (wired in Phase 0 — `vitest.config.mts`,
  `test/apply-migrations.ts`).
- Coverage: `@vitest/coverage-istanbul` (the pool rejects the v8 provider — ADR 0001),
  threshold per doc 08.
- Integration tests dispatch through `exports.default.fetch(...)` from `cloudflare:workers`
  (verified pattern).

## Lint / format / types

- ESLint 10.8.0 flat config (`typescript-eslint` 8.65) — `npm run lint`.
- Prettier 3.9.6 — `npm run format` / `format:check` (gates).
- Node engines: `>= 22` (package.json; Wrangler supports Current/Active/Maintenance Node —
  verified — and the devcontainer pins the Active LTS, ADR 0004).

## Devcontainer (ADR 0004)

- Image: `mcr.microsoft.com/devcontainers/typescript-node:5.0.3-24-bookworm` — Node 24
  (Active LTS), Debian bookworm; exact tag verified against the MCR registry in Phase 0
  (ADR 0001).
- `postCreateCommand`: `npm install && npm run db:local:migrate` (local D1 schema ready on
  first boot); port 8787 forwarded for `wrangler dev`.
- No Cloudflare credentials in the image/config; `.env.example` / `.dev.vars.example` hold
  placeholders only (ADR 0001 placeholder policy). A fresh clone + devcontainer can
  install → build → typecheck → lint → test → `wrangler dev` with zero cloud setup
  (reproducibility requirement).

## Bundle-size guard

- Free-plan Worker limit: **3 MB compressed / 64 MB uncompressed** (verified limits page).
  `npm run build` = `wrangler deploy --dry-run --outdir dist` prints size; it is a gate from
  S05 (S05 AC). Two tiny runtime deps + no framework keep this comfortably green (risk R5).
