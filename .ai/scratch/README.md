# scratch/

Disposable working area for agent roles and ad-hoc analysis.

- Contents are **git-ignored** — anything durable must be promoted to `docs/` or `.ai/`
  (see `.ai/workflows/knowledge-promotion.md`).
- Prefer role-specific `.work/<role>/` for long-lived task notes; use this only for short-lived
  exploration.
- Clean up when done.
